# Конвертер файлов (PWA App)

Готовое к деплою Progressive Web App (PWA) приложение для конвертации файлов прямо в браузере без отправки на сервер.

## Что внутри проекта
- `index.html` — основная разметка с мета-тегами для iOS/Android и подключением PWA-манифеста.
- `style.css` — выделенные стили с поддержкой тёмной/светлой темы и безопасных зон экрана (`safe-area-inset`).
- `app.js` — логика конвертации, переключатель темы и кнопка установки приложения на телефон/ПК.
- `manifest.webmanifest` — манифест веб-приложения для установки на главный экран (Standalone-режим без адресной строки браузера).
- `sw.js` — Service Worker для кэширования интерфейса и библиотек (работает даже офлайн после первого открытия).
- `icons/` — набор иконок (`192x192`, `512x512`, `apple-touch-icon.png`, `favicon.png`, `icon.svg`).
- `vercel.json` / `package.json` — конфигурации для мгновенного деплоя.

## Как задеплоить за 1 минуту

### Вариант 1: Vercel или Netlify (проще всего — перетаскиванием)
1. Распакуй архив `file-converter-pwa.zip`.
2. Перейди на [app.netlify.com/drop](https://app.netlify.com/drop) или [vercel.com](https://vercel.com).
3. Перетащи папку проекта в окно браузера — ты сразу получишь HTTPS-ссылку.

### Вариант 2: GitHub Pages
1. Создай репозиторий на GitHub и загрузи в него содержимое папки.
2. Перейди в **Settings → Pages**, выбери ветку `main` и нажми **Save**.

### Как установить как реальное приложение
- **Android / Desktop (Chrome, Edge):** нажми кнопку **«📲 Установить»** в правом верхнем углу приложения.
- **iOS (Safari):** нажми кнопку **«Поделиться»** внизу экрана и выбери **«На экран „Домой“»**.
